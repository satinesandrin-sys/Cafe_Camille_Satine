# Caf-_viz
Projet visualisation de données M2 sur jeu de données du café
https://www.kaggle.com/datasets/fatihb/coffee-quality-data-cqi

Jeu de données 
| Type             | Exemples                                             |
| ---------------- | ---------------------------------------------------- |
| Géographie       | Country of Origin, Region                            |
| Production       | Variety, Processing Method, Altitude                 |
| Exploitation     | Farm Name, Producer, Company                         |
| Récolte          | Harvest Year, Grading Date                           |
| Quantité         | Number of Bags, Bag Weight                           |
| Qualité physique | Moisture, Defects, Quakers                           |
| Sensoriel        | Aroma, Flavor, Aftertaste, Acidity, Body, Balance... |
| Score final      | Total Cup Points                                     |

Score cible : Total Cup Points ; Il varie de 78 à 89.33 dans le jeu.
